# Create LDAP login UI

Create LDAP login UI

## Usage

``` r
ldap_login_ui(id, title = "Login", logo = NULL, theme_color = "#007bff")
```

## Arguments

- id:

  Namespace ID

- title:

  Login form title

- logo:

  Logo URL to display instead of title (optional)

- theme_color:

  Hex color code for button styling (optional)
